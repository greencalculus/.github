## What we build

| Layer | Content | Standard |
|---|---|---|
| Calculators | Scope 1, 2 & 3 emissions tools | GHG Protocol Corporate Standard |
| Methodology | How our math works | IPCC AR6 GWP values |
| Data | Open emission factor datasets | IEA Global Energy Review 2026 |
| Standards | Citable reference pages | CSRD, SBTi, GHG Protocol Land Sector |

## Technical stack

- Zero-dependency Vanilla JS — no jQuery, no Bootstrap
- CSS `@layer` architecture with fluid `clamp()` typography
- `WebApplication` JSON-LD schema on every tool
- Tabular-nums precision rendering via JetBrains Mono

## Open resources in this org

- **emission-factors** — curated CO₂e factor datasets (CSV + JSON)
- **gc-schema-templates** — `WebApplication` JSON-LD boilerplate for carbon tools
- **methodology-docs** — formal documentation of our calculation approach
