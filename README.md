# .github

Organisation-wide defaults for [GreenCalculus](https://github.com/greencalculus).

- [`profile/README.md`](./profile/README.md) — the org profile page shown at
  github.com/greencalculus
- [`SECURITY.md`](./SECURITY.md), [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md),
  [`CONTRIBUTING.md`](./CONTRIBUTING.md) — inherited by every repository that
  doesn't ship its own
- [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE) and
  [`PULL_REQUEST_TEMPLATE.md`](./.github/PULL_REQUEST_TEMPLATE.md) — the same,
  for issues and pull requests

A repository with its own copy of any of these overrides the default. Change it
here to change it everywhere else.
